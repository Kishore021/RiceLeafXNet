RiceLeafXNet

RiceLeafXNet is an AI-based smart agriculture system designed for rice leaf disease classification using deep learning and image-based analysis. The system allows users to upload a rice leaf image and obtain an automated disease classification result through trained deep learning models.

Project Overview

Project Purpose

The main purpose of RiceLeafXNet is to provide an AI-assisted approach for identifying diseases in rice leaves from digital images.

Image Analysis

The system accepts rice leaf images, processes the image and passes it through trained deep learning models for classification.

Web Application

A Flask-based web interface provides the user interface for image upload, prediction, authentication and prediction history.

Project Structure

User Interface

HTML, CSS, Bootstrap and JavaScript provide the web interface for login, profile, image upload, model selection, prediction and result display.

Flask Application Layer

Flask handles application routes, authentication, user requests, image uploads, model selection, predictions and database operations.

Deep Learning Layer

TensorFlow/Keras trained models analyze the uploaded rice leaf image and produce a disease classification result.

Model Storage

Trained model files are stored inside the project's static Models directory and loaded by the prediction module.

Database Layer

The database stores application data such as user information and scan history.

How RiceLeafXNet Works

1
User Login

The user logs into the application to access the rice leaf disease detection features.

2
Upload Image

A rice leaf image is selected and uploaded through the web interface.

3
AI Prediction

The selected deep learning model processes the image and predicts the disease class.

4
Result

The predicted disease and confidence information are displayed to the user and can be stored in scan history.

Deep Learning Models

EfficientNet

A convolutional neural network architecture used for efficient image classification.

DenseNet

A densely connected CNN architecture used to extract image features for disease classification.

ResNet

A residual neural network architecture used for deep image feature learning and classification.

Uses and Benefits

AI-Assisted Detection

Helps users identify the likely rice leaf class from an uploaded image using trained deep learning models.

Educational Application

Can be used as an academic demonstration of computer vision, transfer learning, deep learning and Flask web deployment.

Model Comparison

Multiple deep learning architectures can be used within the application for image classification and comparison.

Prediction History

Authenticated users can maintain and review their previous rice leaf classification results.

Project Objective

RiceLeafXNet aims to demonstrate how artificial intelligence and deep learning can be integrated with a web application to perform image-based rice leaf disease classification. The project combines a user-friendly Flask interface with trained CNN-based models so that a user can upload a rice leaf image, obtain a predicted class and review the prediction result through the application.
