Key Features

RiceLeafXNet provides a straightforward workflow for uploading, analyzing and reviewing rice leaf classification results.

Image-Based Detection

Upload a rice leaf image through the web interface and use it as input for AI-based classification.

Multiple AI Models

The system provides three deep learning architectures: EfficientNetV2B0, DenseNet121 and ResNet152.

Fast Classification

The trained models process the uploaded image and return a predicted rice leaf class through the Flask application.

Scan History

Logged-in users can review previous scan results through their profile and history section.

Secure User Access

User authentication, profile management and security verification are integrated into the application.

Responsive Interface

The Bootstrap-based interface is designed to work across desktop, tablet and mobile screen sizes.

Deep Learning Models

RiceLeafXNet includes three trained transfer learning architectures for rice leaf image classification.

01
EfficientNetV2B0

A compact convolutional architecture used as the primary model in the current application.

02
DenseNet121

A densely connected convolutional network included as an alternative classification model.

03
ResNet152

A deep residual network included for additional model-based classification.
