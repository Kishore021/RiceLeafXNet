Deep Learning Models

RiceLeafXNet uses deep learning and transfer learning techniques to classify rice leaf images. The application provides multiple CNN-based architectures for image classification and model comparison.

Models Used in RiceLeafXNet

EfficientNetV2B0

EfficientNetV2B0 is designed to provide an effective balance between model performance and computational efficiency. In RiceLeafXNet, it is used as one of the deep learning models for rice leaf image classification.

CNN Transfer Learning

DenseNet121

DenseNet121 uses dense connections between network layers to encourage feature reuse and efficient information propagation. It is used in RiceLeafXNet to learn visual features from rice leaf images.

CNN Transfer Learning

ResNet152

ResNet152 uses residual connections to support deep feature learning. In RiceLeafXNet, it provides another CNN-based approach for classifying rice leaf images.

CNN Transfer Learning

How the Models Work

1
Input Image

The user uploads a rice leaf image through the web application.

2
Preprocessing

The image is converted to RGB and resized to the required 224 × 224 input size.

3
Model Prediction

The selected trained model analyzes the image and generates class probabilities.

4
Classification

The highest-probability class is displayed as the prediction result.

Model Features

Transfer Learning

Pre-trained image classification architectures are adapted for the rice leaf classification task.

Image Classification

The models process rice leaf images and classify them into supported categories.

Probability-Based Result

Model outputs are converted into class probabilities and the predicted class is selected.

Multiple Architectures

RiceLeafXNet integrates EfficientNet, DenseNet and ResNet models within the same application.

Automated Prediction

Once an image is uploaded, the classification process is performed automatically by the selected model.

Web Integration

The trained models are integrated into a Flask web application for convenient user interaction.

Classification Classes

The trained classification system contains the following five rice leaf classes:

Brown Spot Healthy Hispa Leaf Blast Neck Blast

Model Technology Stack

Python

TensorFlow

Deep learning framework used for model training and inference.

Keras

High-level deep learning API used to build and load the models.

Flask

Web framework used to integrate trained models with the application.
